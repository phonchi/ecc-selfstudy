§4.1

每一次加點都要付一次反元素

動機

第 2 章的加法公式裡，$\lambda$ 是一個分數，所以每一次加點或倍點都要算一次 $\mathbb F_p$ 的反元素。第 1 章說過，一次反元素大約等於 80 到 100 次乘法。一次 256 位元的純量乘法要做約 255 次倍點與 128 次加點，光是反元素就要將近四萬次乘法。

解法很像小學的分數運算：先不要約分。把分母另外存起來，一路只做乘法；等整個純量乘法做完，最後才做一次除法。代價是每一步要多做幾次乘法，但省下的反元素多得多。

§4.2

Jacobian 座標

用三個數 $(X:Y:Z)$ 表示一個點，約定

$$(X:Y:Z)\ \longmapsto\ \left(\frac{X}{Z^2},\ \frac{Y}{Z^3}\right),\qquad Z\ne0 .$$

同一個點有很多種寫法：對任意 $\lambda\ne0$，$(\lambda^2X:\lambda^3Y:\lambda Z)$ 代表同一點。這是一個加權射影空間（權重 2, 3, 1），和第 2 章的普通射影座標 $(X:Y:Z)\mapsto(X/Z,Y/Z)$ 不同；兩種都可以用，Jacobian 的倍點公式比較省。$Z=0$ 的那一類（例如 $(1:1:0)$）就是無窮遠點 $\mathcal O$。代進曲線方程，Jacobian 座標滿足

$$Y^2 = X^3 + aXZ^4 + bZ^6 .$$
  • 判斷相等不能直接比座標。$(X_1:Y_1:Z_1)$ 與 $(X_2:Y_2:Z_2)$ 是同一點，當且僅當 $X_1Z_2^2=X_2Z_1^2$ 且 $Y_1Z_2^3=Y_2Z_1^3$（交叉相乘）。
  • 進入很便宜：$(x,y)\mapsto(x:y:1)$。離開要一次反元素：算 $Z^{-1}$，再算 $x=XZ^{-2}$、$y=YZ^{-3}$。
§4.3

公式與成本

把仿射公式中的 $x_i=X_i/Z_i^2$、$y_i=Y_i/Z_i^3$ 代進去、通分，分母全部收進新的 $Z_3$，就得到只有乘法的公式。下表是 Explicit-Formulas Database（EFD）中常用的幾組，$\mathbf M$ 是乘法、$\mathbf S$ 是平方、$\mathbf I$ 是反元素，乘小常數與加減不計。

兩個常見的技巧：

  • 混合加法（mixed addition）：double-and-add 裡加上的永遠是同一個 $P$，它可以保持仿射形式（$Z=1$），省下好幾次乘法。
  • $a=-3$：倍點要算 $3X^2+aZ^4$。當 $a=-3$ 時，它等於 $3(X-Z^2)(X+Z^2)$，不必乘 $a$，也不必算 $Z^4$；倍點從 1M + 8S（再乘一次 $a$）變成 3M + 5S。這就是 NIST 曲線都取 $a=-3$ 的原因。

Hankerson–Menezes–Vanstone 的表 3.3 列出的數字略有不同（$a=-3$ 時 Jacobian 倍點 4M + 4S、混合加點 8M + 3S），因為公式在乘法與平方之間有不同取捨，總量差不多。

Jacobian 座標的倍點與混合加點（為了清楚，不追求最少的乘法次數）
# Jacobian 座標：(X : Y : Z) 代表仿射點 (X/Z^2, Y/Z^3)；Z = 0 代表 O。
def to_jacobian(P):
    return (1, 1, 0) if P is O else (P[0], P[1], 1)


def from_jacobian(J, p):
    X, Y, Z = J
    if Z % p == 0:
        return O
    zi = inv_fermat(Z, p)               # 整個純量乘法最後只求這一次反元素
    return (X * zi * zi % p, Y * zi * zi * zi % p)


def jac_double(J, a, p):
    X, Y, Z = J
    if Z == 0 or Y == 0:
        return (1, 1, 0)
    XX, YY, ZZ = X * X % p, Y * Y % p, Z * Z % p
    S = 4 * X * YY % p
    M = (3 * XX + a * ZZ * ZZ) % p
    X3 = (M * M - 2 * S) % p
    Y3 = (M * (S - X3) - 8 * YY * YY) % p
    Z3 = 2 * Y * Z % p
    return (X3, Y3, Z3)


def jac_add_affine(J, Q, a, p):
    """混合加法：J 是 Jacobian 點，Q 是仿射點（Z = 1）。"""
    if Q is O:
        return J
    X1, Y1, Z1 = J
    if Z1 == 0:
        return to_jacobian(Q)
    x2, y2 = Q
    Z1Z1 = Z1 * Z1 % p
    U2 = x2 * Z1Z1 % p
    S2 = y2 * Z1 * Z1Z1 % p
    H = (U2 - X1) % p
    r = (S2 - Y1) % p
    if H == 0:
        return jac_double(J, a, p) if r == 0 else (1, 1, 0)
    HH = H * H % p
    HHH = H * HH % p
    V = X1 * HH % p
    X3 = (r * r - HHH - 2 * V) % p
    Y3 = (r * (V - X3) - Y1 * HHH) % p
    Z3 = Z1 * H % p
    return (X3, Y3, Z3)


def scalar_mult_jacobian(k, P, a, p):
    R = (1, 1, 0)
    for bit in bin(k)[2:]:
        R = jac_double(R, a, p)
        if bit == "1":
            R = jac_add_affine(R, P, a, p)
    return from_jacobian(R, p)

§4.6

小結：成本鏈往下走一層

換成 Jacobian 座標之後，一次 256 位元的純量乘法大約只要三千多次 $\mathbb F_p$ 乘法，再加上最後一次反元素。只要反元素比大約 5 次乘法還貴（實際上一定是），Jacobian（加權射影）座標就划算。於是整個 ECC 的速度，幾乎完全取決於一次 $\mathbb F_p$ 乘法有多快：這就是第 6 到第 9 章的主題。第 5 章先把純量乘法本身的排程講清楚。
