§1.1

為什麼座標要放在有限體裡

動機

橢圓曲線的加法公式（第 2 章）要用到加、減、乘、除。若座標是實數，電腦只能存近似值，誤差會一路累積，密碼學無法接受。我們需要一個有限的集合，在裡面四則運算都精確而且封閉：這就是有限體。

本站只用最簡單的一種：質數 $p$ 所定的 $\mathbb F_p=\{0,1,\dots,p-1\}$，運算都取模 $p$。實際使用的 $p$ 大約有 224 到 521 位元。本章說明四則運算各自怎麼做、哪一個最貴；「除法最貴」這件事會一路影響到第 4 章的座標選擇。

§1.2

加、減、乘：先算整數，再取模

對 $a,b\in\mathbb F_p$，

$$a\oplus b=(a+b)\bmod p,\qquad a\ominus b=(a-b)\bmod p,\qquad a\otimes b=(ab)\bmod p .$$

$\mathbb Z/p\mathbb Z$ 是一個體（field），正是因為 $p$ 是質數：每個非零元素都有乘法反元素。若模數是合數 $m$，與 $m$ 不互質的元素就沒有反元素。

  • 加法與減法很便宜。$0\le a+b<2p$，所以只要算整數和，若 $\ge p$ 就減一次 $p$。減法同理：結果為負就加一次 $p$。成本與字組數 $k$ 成正比。
  • 乘法是主角。整數乘積 $ab$ 有 $2k$ 個字組，第 6 章算它；接著要把它化簡回 $[0,p)$，第 7–9 章處理。本站把這一整套（乘積加化簡）記成一次 $\mathbf M$，平方記成 $\mathbf S$。平方可以利用對稱性少算一些部分積，所以常假設 $\mathbf S\approx 0.8\,\mathbf M$。
  • 除法是乘上反元素。$a/b=a\cdot b^{-1}$，問題就變成：$b^{-1}$ 怎麼算、要花多少？
§1.3

反元素之一：延伸歐幾里得演算法

因為 $\gcd(a,p)=1$，Bézout 定理保證存在整數 $s,t$ 使 $sa+tp=1$。兩邊模 $p$，就得到 $sa\equiv1$，所以 $a^{-1}=s\bmod p$。延伸歐幾里得演算法在做輾轉相除的同時，記下每一個餘數如何寫成 $a$ 與 $p$ 的組合。

手算小例：$5^{-1}\bmod 7$
商 $q$餘數 $r$7 的係數5 的係數關係
—7107 = 7·1 + 5·0
—5015 = 7·0 + 5·1
121−12 = 7·1 + 5·(−1)
21−231 = 7·(−2) + 5·3

每一列等於「上上列 − $q$ × 上一列」。餘數到 1 時，5 的係數是 3，所以 $5^{-1}\equiv3\pmod 7$。驗算：$5\cdot3=15=2\cdot7+1$。

步數大約與 $\log p$ 成正比（Lamé 定理），但每一步都是一次多字組的除法，而且步數與商都隨輸入而變。這兩點讓它在實作上不如看起來便宜，也不容易做成常數時間。

兩種求反元素的方法
def egcd(a, b):
    """回傳 (g, s, t)，使 s*a + t*b = g = gcd(a, b)。"""
    s0, s1, t0, t1 = 1, 0, 0, 1
    while b != 0:
        q = a // b
        a, b = b, a - q * b
        s0, s1 = s1, s0 - q * s1
        t0, t1 = t1, t0 - q * t1
    return a, s0, t0


def inv_euclid(a, p):
    g, s, _ = egcd(a % p, p)
    if g != 1:
        raise ZeroDivisionError("a 在模 p 下沒有反元素")
    return s % p


def inv_fermat(a, p):
    # p 是質數：a^(p-1) = 1，所以 a^(p-2) 就是 a 的反元素
    return pow(a, p - 2, p)
§1.4

反元素之二：Fermat 小定理

對 $a\ne0$，$a^{p-1}\equiv1\pmod p$，所以

$$a^{-1}\equiv a^{p-2}\pmod p .$$

冪次用平方-乘（square-and-multiply）計算：把 $p-2$ 寫成二進位，由高位讀起，每讀一位先平方，讀到 1 再乘上 $a$。所需次數大約是 $\log_2 p$ 次平方，加上 $p-2$ 中 1 的個數那麼多次乘法。

以 P-256 為例，直接照二進位做，大約是 255 次平方加 127 次乘法。實作上會針對固定的 $p-2$ 設計加法鏈（addition chain），把乘法次數壓到十幾次，但平方還是約 255 次。好處是步驟完全固定、只用到乘法，所以容易做成常數時間；缺點是很多次乘法。

順帶一提：平方數

同樣的冪次技巧還能判斷非零的 $r$ 是不是平方數：$r^{(p-1)/2}\equiv1$ 表示是，$\equiv-1$ 表示不是（Euler 判別法）。$\mathbb F_p^*$ 中恰好一半的元素是平方數。曲線上某個 $x$ 有沒有對應的點，取決於 $x^3+ax+b$ 是不是平方數；第 3 章估計曲線上有幾個點時，就會用到這個事實。

§1.6

為什麼反元素讓人頭痛

不管用哪一種方法，一次反元素都比一次乘法貴得多。工程上用一個比值 $\mathbf I/\mathbf M$ 來描述它：一次反元素相當於幾次乘法。這個數字隨平台、模數大小與實作方式而變，常見的假設在 80 到 100 之間（本站的成本估算一律取 $\mathbf I=100\,\mathbf M$），有些硬體上也可能只有 10 到 20。

第 2 章會看到，曲線上每加一次點，仿射公式就要算一次除法。一次純量乘法要加幾百次點，若每次都付一次反元素，成本會被反元素主導。第 4 章的解法是：把除法全部延到最後只做一次。
