§3.1

正著算容易，倒著算很難

動機

第 0 章的 ECDH 是這樣運作的：大家共用曲線上的一個基點 $G$；Alice 選祕密整數 $a$、公開 $aG$，Bob 選 $b$、公開 $bG$，雙方各自算出同一個點 $abG$。這個協定要安全，必須同時滿足兩件事：

  • 正著算容易：給定 $k$ 與 $P$，算 $kP$ 只要幾百次倍點和加點（第 5 章）。
  • 倒著算很難：給定 $P$ 與 $Q=kP$，找回 $k$ 在實際上做不到。這叫橢圓曲線離散對數問題（elliptic curve discrete logarithm problem，ECDLP）。

第 2 章給了我們一個群。本章要回答：這個群有多大？它的子群長什麼樣子？在什麼條件下 ECDLP 才真的難？答案決定了實際的曲線怎麼挑，也決定了「256 位元的曲線提供 128 位元安全」這句話的來源。

整章的數值例子用兩條第 2 章的玩具曲線，都在 $\mathbb F_{97}$ 上：

$$E_A:\ y^2=x^3+2x+3,\qquad E_B:\ y^2=x^3-3x+6 .$$
§3.2

點有多少個：Hasse 定理

先數點。固定 $x\in\mathbb F_p$，令 $f(x)=x^3+ax+b$。方程式 $y^2=f(x)$ 的解數取決於 $f(x)$ 是不是平方：

  • $f(x)$ 是非零的平方剩餘（quadratic residue）：兩個點 $(x,\pm y)$；
  • $f(x)=0$：一個點 $(x,0)$；
  • $f(x)$ 是非剩餘：沒有點。

三種情形都可以寫成 $1+\left(\frac{f(x)}{p}\right)$（Legendre 符號）。加上無窮遠點 $\mathcal O$，

$$N=\#E(\mathbb F_p)=p+1+\sum_{x\in\mathbb F_p}\left(\frac{f(x)}{p}\right).$$

$\mathbb F_p^*$ 裡恰好一半的元素是平方，所以直覺上大約一半的 $x$ 貢獻兩個點、另一半貢獻零個，總數大約是 $p+1$。偏差來自 Legendre 符號的和；如果把它們當成隨機的 $\pm1$，和的大小應該是 $\sqrt p$ 的數量級。Hasse（1933）證明了這個直覺的精確版本：

$$\bigl|\,N-(p+1)\,\bigr|\le 2\sqrt p .$$

整數 $t=p+1-N$ 叫做 Frobenius 的跡（trace of Frobenius）。對數論背景的讀者：這正是曲線版本的 Riemann 假設，後來由 Weil 推廣到一般的代數曲線（Washington 第 4 章）。

數一數：$\mathbb F_{97}$ 上的兩條玩具曲線

在 $E_A$ 上，97 個 $x$ 之中有 48 個使 $f(x)$ 是非零平方、46 個是非剩餘、3 個使 $f(x)=0$，所以 $N=2\cdot48+3+1=100$。在 $E_B$ 上是 53、44、0 個，$N=2\cdot53+1=107$。

$p=97$ 時 Hasse 區間是

$$[\,98-2\sqrt{97},\ 98+2\sqrt{97}\,]\approx[78.30,\ 117.70],$$

兩者都落在裡面。

Hasse 界的是群的大小

Hasse 定理說的是整個群的點數 $N$，與個別點的階無關。點的階可以小到 2（下一節就有例子），只要它整除 $N$。

真實大小的曲線也一樣。P-256 的 $p$ 與群階 $n$ 都是 256 位元的數（它的餘因子是 1，所以 $N=n$），而 $t=p+1-n$ 只有 127 位元，比 $2\sqrt p$（129 位元）小：相對於 $p$ 本身，$N$ 與 $p+1$ 的差只是約 $2^{-129}$ 的比例。實際的 $N$ 不是用上面的和去數（那要 $p$ 步），而是用 Schoof 演算法及其改良（SEA），它們的時間是 $\log p$ 的多項式（Washington 第 4 章）。

數點、點的階，以及 baby-step giant-step
from math import isqrt


def count_points(a, b, p):
    """#E(F_p) = p + 1 + sum_x (x^3+ax+b | p)：每個 x 貢獻 1 + Legendre 符號個點。"""
    N = 1                                          # 無窮遠點 O
    for x in range(p):
        r = (x * x * x + a * x + b) % p
        if r == 0:
            N += 1                                 # y = 0，一個點
        elif pow(r, (p - 1) // 2, p) == 1:
            N += 2                                 # 平方剩餘，兩個點 (x, ±y)
    return N


def point_order(P, a, p):
    """最小的 k >= 1 使 kP = O。依 Lagrange 定理，它整除 #E。"""
    k, R = 1, P
    while R is not O:
        R = ec_add(R, P, a, p)
        k += 1
    return k


def bsgs(G, Q, n, a, p):
    """Baby-step giant-step：找 k 使 kG = Q，G 的階為 n。約 2*sqrt(n) 次點加法。"""
    m = isqrt(n - 1) + 1                           # m = ceil(sqrt(n))
    baby, R = {}, O
    for j in range(m):                             # baby steps：jG
        baby.setdefault(R, j)
        R = ec_add(R, G, a, p)
    step = ec_neg(scalar_mult(m, G, a, p), p)      # -mG
    R = Q
    for i in range(m):                             # giant steps：Q - i*mG
        if R in baby:
            return (i * m + baby[R]) % n
        R = ec_add(R, step, a, p)
    return None
§3.3

子群、階與餘因子

對曲線上的點 $P$，最小的正整數 $m$ 使 $mP=\mathcal O$ 叫做 $P$ 的階（order）。$P,2P,\dots,mP=\mathcal O$ 構成一個循環子群 $\langle P\rangle$。由 Lagrange 定理，

$$\operatorname{ord}(P)\ \big|\ N .$$

反過來不成立：$N$ 的因數不一定都是某個點的階。$E_A$ 就是例子。它的 $N=100$，99 個非 $\mathcal O$ 的點的階分布如下（逐點計算）：

階25102550
點數34122060

沒有階為 4、20 或 100 的點。原因是 $x^3+2x+3$ 在 $\mathbb F_{97}$ 上有三個根（$x=30, 68, 96$），給出三個階為 2 的點 $(x,0)$；循環群只有一個階為 2 的元素，所以 $E_A(\mathbb F_{97})$ 不是循環群，而是 $\mathbb Z/2\times\mathbb Z/50$。一般而言 $E(\mathbb F_p)\cong\mathbb Z/n_1\times\mathbb Z/n_2$，其中 $n_1\mid n_2$（Washington 定理 4.1），而且 $n_1\mid p-1$（Washington 推論 3.11，由 Weil 配對得到）。$E_B$ 的情形最乾淨：$N=107$ 是質數，每個非 $\mathcal O$ 的點的階都是 107。

密碼學實際用的是一個質數階子群

實務上把群階寫成

$$N=h\cdot n,\qquad n\ \text{是大質數},\quad h\ \text{很小（餘因子，cofactor）}.$$

標準會給定一個階為 $n$ 的基點 $G$，ECDH 與 ECDSA 都只在 $\langle G\rangle$ 裡運算。$E_B$ 是 $h=1$、$n=107$；$E_A$ 的 $100=2^2\cdot5^2$，最大的質因數只有 5，也就是 $n=5$、$h=20$，這樣的曲線不會拿來用。真實曲線中，P-256 與 P-521 的 $h=1$（SP 800-186），Curve25519 的 $h=8$（RFC 7748）。

兩個模數：$p$ 與 $n$

座標是 $\mathbb F_p$ 的元素，所有點運算都在模 $p$ 下做。純量 $k$ 只在模 $n$ 下有意義，因為 $nG=\mathcal O$ 讓 $(k+n)G=kG$；祕密金鑰取在 $[1,n-1]$，ECDSA 的簽章公式也在模 $n$ 下計算。P-256 的 $p$ 形狀特殊，可以用第 7 章的折疊；$n$ 沒有特殊形狀，所以 ECDSA 需要第 8、9 章的一般方法。

餘因子 $h>1$ 時要小心：對方傳來的點可能落在階很小的子群裡（例如 $E_A$ 的三個 2 階點），使共用祕密只剩幾種可能。實作會先檢查收到的點確實在曲線上，再確認它位於 $\langle G\rangle$ 中（例如檢查 $nQ=\mathcal O$）；另一種做法是把共用的點乘上 $h$（cofactor multiplication），若結果是 $\mathcal O$ 就拒絕。只乘 $h$ 而不做這個拒絕，小階的輸入仍會得到可預測的 $\mathcal O$。

§3.4

ECDLP 與攻擊

問題：給定階為 $n$ 的 $G$ 與 $Q\in\langle G\rangle$，找 $k$ 使 $Q=kG$。

一般方法：$\sqrt n$ 的障礙

  • 暴力搜尋：依序算 $G,2G,3G,\dots$，最多 $n$ 次加點。
  • Baby-step giant-step（BSGS）：取 $m=\lceil\sqrt n\,\rceil$，把 $k$ 寫成 $k=im+j$，$0\le i,j<m$。先存下所有 $jG$（baby steps），再依序算 $Q-i\,(mG)$（giant steps），碰到表中的點就得到 $k$。時間與記憶體都約 $\sqrt n$。
  • Pollard rho：用一個看似隨機的走法在 $\langle G\rangle$ 中產生點列，等它出現碰撞。由生日悖論，期望約 $\sqrt{\pi n/2}$ 步，只需常數記憶體，而且可以多台機器平行。這是目前對一般曲線最好的攻擊（HMV §4.1）。
BSGS 小例：$E_B$，$n=107$

取 $G=(0,43)$、$Q=(25,91)$。$m=\lceil\sqrt{107}\,\rceil=11$。表中存 $0G,\dots,10G$；giant step 依序算 $Q, Q-11G, Q-22G,\dots$，在 $i=5$ 時碰到 $3G$，所以 $k=5\cdot11+3=58$。總共不到 $2m=22$ 次加點，暴力搜尋則要 58 次。

對 P-256，$n$ 是 256 位元，Pollard rho 的期望步數 $\sqrt{\pi n/2}$ 約為 $2^{128.3}$。這就是「256 位元曲線約有 128 位元安全」的來源：安全強度是群階位元數的一半。

Pohlig–Hellman：為什麼要大質數因子

若 $G$ 的階不是質數，可以把問題分解到每個質數冪的子群上分別解，再用中國剩餘定理拼回 $k$。工作量由這個階的最大質因數 $q$ 決定，大約 $\sqrt q$。$E_A$ 的 $N=100=2^2\cdot5^2$，最大的質因數是 5，離散對數幾乎可以手算。所以實際的曲線一定讓 $n$ 是大質數，而且 $h$ 很小。

與 $\mathbb F_p^*$ 的差別：沒有指標演算法

在 $\mathbb F_p^*$ 上，離散對數有次指數時間的指標演算法（index calculus）：利用「很多整數可以拆成小質數的乘積」，先求出小質數的對數，再拼出目標。數域篩法把它推到 $L_p[1/3]$ 的複雜度，這也是有限體 Diffie–Hellman 與 RSA 需要 3072 位元，ECC 只要 256 位元的原因（第 0 章）。對質數體上一般選取的曲線，目前不知道有類似「小質數」的概念可用，最好的攻擊仍是 $\sqrt n$ 的一般方法（Washington 第 5 章）。

要避開的曲線

「一般選取」有例外。下面兩類曲線有特殊結構，ECDLP 會變簡單：

  • 異常曲線（anomalous curve，$N=p$）：Smart、Satoh–Araki 與 Semaev 各自證明，這時可以把問題提升到 $p$ 進數上，在多項式時間內解出 $k$（Washington §5.4）。例如 $\mathbb F_{127}$ 上的 $y^2=x^3-3x+5$ 恰好有 127 個點（逐點計算確認），它的跡 $t=1$。
  • 嵌入次數小的曲線：嵌入次數是使 $n\mid p^k-1$ 的最小 $k$。MOV 與 Frey–Rück 攻擊用配對（pairing）把 $\langle G\rangle$ 嵌入 $\mathbb F_{p^k}^*$，在那裡就能用指標演算法。$k$ 很小時這是致命的。例如 $\mathbb F_{103}$ 上的超奇異曲線 $y^2=x^3+x$ 有 $104=p+1$ 個點，最大質因數 $n=13$，而 $13\mid103+1$，所以 $k=2$（Washington §5.3）。

相對地，$E_B$ 的 $n=107$ 對 $p=97$ 的嵌入次數是 106（逐一計算 $97^k\bmod107$）。標準曲線在發布前都排除了這些情形，並且選擇 $h$ 小、$n$ 為大質數的曲線（SP 800-186；HMV §4.1）。

§3.5

互動：$kP$ 的軌跡與點的階

點雲是曲線在 $\mathbb F_{97}$ 上的所有點。點一下任何一點當作起點 $P$（或用下拉選單挑一個指定階的點），再播放：每一步加上 $P$，紫色線依序連起 $P,2P,3P,\dots$，直到回到 $\mathcal O$。走過的步數就是 $P$ 的階，右側檢查它是否整除 $N$。

在 $E_A$ 上試試不同的點：軌跡的長度只會是 2、5、10、25 或 50。在 $E_B$ 上，每一條軌跡都走遍全部 106 個仿射點。點的位置看起來毫無規律，這正是「從 $kP$ 看不出 $k$」的直觀寫照。

§3.6

互動：Hasse 區間裡的點數分布

固定 $p$ 與 $a$，讓 $b$ 跑過所有使曲線非奇異（$4a^3+27b^2\not\equiv0$）的值，逐條數出 $N=\#E(\mathbb F_p)$，畫成直方圖。淺色帶是 Hasse 區間 $[\,p+1-2\sqrt p,\ p+1+2\sqrt p\,]$；所有長條都落在帶內。藍色是一般的 $N$，綠色長條的 $N$ 是質數（$h=1$ 的候選），紅色長條是 $N=p$ 的異常曲線。點一下長條可以看到是哪些 $b$。
