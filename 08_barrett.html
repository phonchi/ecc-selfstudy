第 8 章 · Barrett Reduction

Barrett 化簡

任何模數都適用：預先算好 1/m 的近似，用乘法與移位估出商

成本鏈協定 ECDH→純量乘法 kP→加點／倍點→模乘 mod p→字組乘法

8.1當模數沒有好看的形狀

動機

第 7 章的折疊只對設計者特別挑過的 $p$ 有效。有些模數卻由不得我們挑，ECC 本身就有例子：ECDSA 簽章（注意 0.7）除了在 $\mathbb F_p$ 裡做點運算，還要在模基點的階 $n$ 下做加法、乘法與反元素。$n$ 由曲線決定，P-256 的 $n$ 是一串看不出規律的 256 位元數，沒有任何可以折疊的結構。RSA 的模數則是兩個隨機質數的乘積。

因此需要一個對一般模數 $m$ 都有效、又不做長除法的化簡方法。本章與第 9 章各給一個。Barrett（1986）的想法是：除法很貴，但「除以同一個數」可以預先準備。同一個模數要用上幾千次，所以先花一次功夫算出 $1/m$ 的近似值，之後每次化簡只用乘法和移位估出商。

8.2用預先算好的倒數估計商

由 定義 1.1，$x\bmod m=x-m\lfloor x/m\rfloor$，困難只在商 $\lfloor x/m\rfloor$。若事先知道 $1/m$ 的近似值，商就能用一次乘法估出來。在電腦上，「近似 $1/m$」要寫成整數：以 $\beta$ 為基底（定義 6.1），預先算一個定點數 $\mu\approx\beta^{2s}/m$；之後「除以 $\beta^j$」只是丟掉最低 $j$ 個字組，不必真的做除法。

定義 8.1Barrett 常數HAC §14.3.3

設模數 $m$ 以 $\beta$ 為基底恰有 $s$ 個字組，即 $\beta^{s-1}\le m<\beta^s$。稱

$$\mu=\left\lfloor\frac{\beta^{2s}}{m}\right\rfloor$$

為 $m$ 的 Barrett 常數。$\mu/\beta^{2s}$ 就是 $1/m$ 的定點近似。由 $\beta^{s-1}\le m<\beta^s$ 得 $\beta^s<\mu\le\beta^{s+1}$，所以 $\mu$ 大約有 $s+1$ 個字組。

估商的式子來自把 $x/m$ 拆成三個因子：

$$\frac{x}{m}=\frac{x}{\beta^{s-1}}\cdot\frac{\beta^{2s}}{m}\cdot\frac{1}{\beta^{s+1}} .$$

把第一個因子換成 $\lfloor x/\beta^{s-1}\rfloor$（丟掉 $x$ 的低 $s-1$ 個字組），第二個換成 $\mu$，整體再取整，就得到下面演算法的 $q_3$。

8.3Barrett 化簡：估商、相減、修正

上一節的估商式還帶著實數除法。下面的程序只用移位、兩次截短的乘法與幾次減法，每個前提都寫在輸入裡。

演算法 8.2Barrett 化簡HAC Alg. 14.42
輸入基底 $\beta>3$；模數 $m$，恰有 $s$ 個字組（$\beta^{s-1}\le m<\beta^s$）；整數 $0\le x<\beta^{2s}$；預先算好的 $\mu=\lfloor\beta^{2s}/m\rfloor$（定義 8.1）。
輸出$r=x\bmod m$。
  1. $q_1\leftarrow\lfloor x/\beta^{s-1}\rfloor$，$q_2\leftarrow q_1\cdot\mu$，$q_3\leftarrow\lfloor q_2/\beta^{s+1}\rfloor$。
  2. $r_1\leftarrow x\bmod\beta^{s+1}$，$r_2\leftarrow q_3\cdot m\bmod\beta^{s+1}$，$r\leftarrow r_1-r_2$。
  3. 若 $r<0$，則 $r\leftarrow r+\beta^{s+1}$。
  4. 當 $r\ge m$：$r\leftarrow r-m$。
  5. 回傳 $r$。

所有「除以 $\beta^j$」與「$\bmod\beta^j$」都只是丟掉或保留某些字組。整個過程沒有除法，只有兩次乘法 $q_1\mu$、$q_3m$ 與幾次減法。兩個 $[0,m)$ 中的數相乘，乘積小於 $m^2<\beta^{2s}$，一定符合輸入條件。

演算法是否正確，要看 $q_3$ 離真正的商有多遠。

定理 8.3估計商的誤差HAC Fact 14.43

由帶餘除法（定義 1.1），存在整數 $Q,r$ 使 $x=Qm+r$、$0\le r<m$。在 演算法 8.2 第 1 步中，

$$Q-2\ \le\ q_3\ \le\ Q .$$

（HAC 把餘數記作 $R$；本站的 $R$ 留給第 9 章，所以這裡寫 $r$。）

直覺：$q_3$ 有兩個誤差來源，一是丟掉了 $x$ 的低 $s-1$ 個字組，二是 $\mu$ 本身取過整。兩者都只會讓估計值變小，而且各自讓它少不到 1，所以 $q_3$ 不會超過 $Q$，最多少 2。

第 2–4 步由此而來。真正的差 $x-q_3m=(Q-q_3)m+r$ 落在 $[0,3m)$。因為 $m<\beta^s$ 且 $\beta>3$，有 $3m<\beta^{s+1}$，所以只要知道這個差的低 $s+1$ 個字組就能還原它：第 2 步只算低 $s+1$ 個字組，若相減為負，第 3 步加回 $\beta^{s+1}$。最後 $r<3m$，第 4 步至多減兩次 $m$（HAC Note 14.44）。條件 $\beta>3$ 就是為了這一步。

手算小例：兩次修正真的會發生

取 $m=241$，$\beta=4$。$4^3=64\le241<256=4^4$，所以 $s=4$，$\mu=\lfloor 4^8/241\rfloor=\lfloor 65536/241\rfloor=271$。對 $x=57855<4^8$：

$$q_1=\lfloor 57855/4^3\rfloor=903,\qquad q_2=903\cdot271=244713,$$ $$q_3=\lfloor 244713/4^5\rfloor=238 .$$

真正的商是 $Q=\lfloor 57855/241\rfloor=240$，所以 $q_3=Q-2$，定理 8.3 的下界取到等號。相減得 $r=57855-238\cdot241=497$（$497<4^5$，第 3 步不必加回），再減兩次 241：$497\to256\to15$。驗算：$57855=240\cdot241+15$。

下面的程式中，beta、s 即本文的 $\beta$、$s$，w 是字組大小（$\beta=2^w$）。

Python 參考實作（選讀）：Barrett 化簡（HAC 演算法 14.42）
def barrett_setup(m, w):
    """beta = 2^w，s = m 的字組數，預先算 mu = floor(beta^(2s) / m)。"""
    s = (m.bit_length() + w - 1) // w
    mu = (1 << (2 * s * w)) // m
    return s, mu


def barrett(x, m, w, s, mu):
    """HAC Alg. 14.42：0 <= x < beta^(2s)。回傳 (x mod m, 修正次數)。"""
    q1 = x >> (w * (s - 1))
    q2 = q1 * mu
    q3 = q2 >> (w * (s + 1))            # 商的估計值，比真正的商最多少 2
    mod = 1 << (w * (s + 1))
    r = (x % mod) - (q3 * m % mod)
    if r < 0:
        r += mod
    fixes = 0
    while r >= m:                       # 最多兩次
        r -= m
        fixes += 1
    return r, fixes

8.5成本與取捨

以字組乘法（定義 6.2）計數，HAC Note 14.45 指出兩次乘法都只需要算一部分的字組：

  • $q_3$：$q_2$ 的低 $s+1$ 個字組最後會被丟掉，所以 $q_1\mu$ 只需部分乘積，至多 $(s+1)^2-\binom{s}{2}=(s^2+5s+2)/2$ 次字組乘法（在 $\beta$ 相對於 $s$ 夠大時，被省略的低位只影響一個可以準確算出的進位）。
  • $r_2$：只需要 $q_3m$ 的低 $s+1$ 個字組，至多 $\binom{s+1}{2}+s$ 次。

合計約 $s^2+4s+1$ 次，與一次 $s\times s$ 的乘法同一量級。所以一次 $\mathbf M$（乘積 $s^2$ 次加上化簡）大約是 $2s^2$ 次字組乘法。其他取捨：

  • 預計算：每個模數算一次 $\mu$（一次長除法），之後幾千次化簡共用。
  • 輸出就是普通的 $x\bmod m$：不必像第 9 章那樣先換表示法，所以只做少數幾次乘法時很划算。
  • 修正步驟與資料有關：減 0、1 或 2 次取決於輸入，會造成時間差。常數時間的實作會固定做兩次「條件減法」，用遮罩選結果，不用分支。

Barrett 的做法是從 $x$ 的高位猜商，猜得不準就事後修正。第 9 章從另一端下手：不猜商，改把 $x$ 的低位逐字組消成 0。
