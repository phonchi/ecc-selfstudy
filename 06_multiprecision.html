第 6 章 · Multiprecision Multiplication

大整數乘法

256 位元的數放不進一個暫存器：先切成字組，再逐格相乘

成本鏈協定 ECDH→純量乘法 kP→加點／倍點→模乘 mod p→字組乘法

6.1一個暫存器裝不下的數

動機

第 5 章把一次純量乘法 $kP$ 的成本數成幾千個 $\mathbf M$ 與 $\mathbf S$（定義 1.13）。$\mathbf M$ 是一次 $\mathbb F_p$ 乘法（定義 1.11）：先算整數乘積 $ab$，再把它化簡回 $[0,p)$。本章處理第一步，第 7–9 章處理第二步。

困難在於大小。P-256 的 $p$ 有 256 位元，但處理器的一個暫存器只有 64 位元（嵌入式晶片常常只有 32 位元，甚至 8 位元），硬體的乘法指令一次只能把兩個暫存器大小的數相乘。所以一個 $\mathbb F_p$ 元素必須切成好幾段來存，整數乘積 $ab$ 也必須由許多次「小乘法」拼出來。$\mathbf M$ 的成本主要由這些小乘法的次數決定，本章要數的正是這個次數。

6.2字組與以 $\beta$ 為基底的表示

先把「切成好幾段」說精確：每一段放進一個暫存器，稱為一個字組；整個數就是以 $2^w$ 為基底的展開。

定義 6.1字組、字組大小、基底、以 β 為基底的表示HAC §14.2；HMV §2.2.1

設 $w\ge1$，稱 $w$ 為字組大小（word size），令基底 $\beta=2^w$（實務上 $w=32$ 或 $64$；手算例子也會取 $\beta=4$ 或 $10$）。每個整數 $0\le x<\beta^s$ 都可以唯一寫成

$$x=\sum_{i=0}^{s-1}x_i\,\beta^{\,i},\qquad 0\le x_i<\beta ,$$

記作 $x=(x_{s-1}\cdots x_1x_0)_\beta$，稱為 $x$ 以 $\beta$ 為基底的表示（radix-$\beta$ representation）。每個 $x_i$ 稱為一個字組（word），$s$ 是字組數。

因為 $\beta$ 是 2 的冪，求出 $x_i$ 只是取出 $x$ 的第 $iw$ 到第 $iw+w-1$ 個位元，不需要除法。一個 $L$ 位元的模數需要 $s=\lceil L/w\rceil$ 個字組：

模數位元數 $L$$s$（$w=64$）$s$（$w=32$）
P-25625648
P-384384612
P-521521917

P-521 的 521 位元比 8 個 64 位元字組多出 9 個位元，就得多用一個字組；第 7 章 P-521 的化簡要在字組中間切開，也是這個原因。

定義 6.2字組乘法、單精度乘法HAC §14.2.3

兩個字組 $x_j,y_i\in[0,\beta)$ 的乘積小於 $\beta^2$，可以寫成兩個字組 $(uv)_\beta=u\beta+v$（$u$ 可能是 0）。這個運算稱為一次字組乘法（single-precision multiplication），由硬體的一道乘法指令完成。第 6–9 章以字組乘法的次數作為成本單位；字組的加減法與移位相對便宜，計數時不算。

6.3Schoolbook 乘法

有了字組表示，兩個數的乘積就是展開式

$$x\cdot y=\sum_{i=0}^{s-1}\sum_{j=0}^{s-1}x_j\,y_i\,\beta^{\,i+j}.$$

每一項 $x_jy_i$ 是一次字組乘法，結果要加到輸出的第 $i+j$ 個字組上。加上去以後可能超過一個字組，超出的部分要帶到下一個字組，也就是進位（carry）。下面的演算法就是小學直式乘法：拿 $y$ 的一個字組 $y_i$ 乘遍 $x$ 的每個字組，邊乘邊進位。

演算法 6.3多精度乘法（schoolbook）HAC Alg. 14.12
輸入$x=(x_{s-1}\cdots x_0)_\beta$，$y=(y_{s-1}\cdots y_0)_\beta$。
輸出$x\cdot y=(z_{2s-1}\cdots z_1z_0)_\beta$。
  1. 對 $i=0,1,\dots,2s-1$：$z_i\leftarrow0$。
  2. 對 $i=0,1,\dots,s-1$：
    1. $c\leftarrow0$。
    2. 對 $j=0,1,\dots,s-1$：計算 $(uv)_\beta=z_{i+j}+x_j\,y_i+c$，令 $z_{i+j}\leftarrow v$，$c\leftarrow u$。
    3. $z_{i+s}\leftarrow u$。
  3. 回傳 $(z_{2s-1}\cdots z_0)_\beta$。

做完第 $i$ 列時，$(z_{i+s}\cdots z_0)_\beta=x\cdot(y_i\cdots y_0)_\beta$。內層每一步一次字組乘法，共 $s^2$ 次字組乘法。（HAC 的敘述允許兩個輸入長度不同，各有 $n+1$、$t+1$ 個字組，次數是 $(n+1)(t+1)$，HAC Note 14.15(ii)。HAC 把輸出字組記作 $w_i$；本站的 $w$ 已用來表示字組大小，所以改記為 $z_i$。）

第 2(b) 步的 $z_{i+j}+x_jy_i+c$ 稱為內積運算（inner-product operation）。演算法能成立，關鍵是它的結果永遠放得進兩個字組：

定理 6.4內積運算不會溢位HAC Note 14.15(i)

若 $z_{i+j},x_j,y_i,c\in[0,\beta)$，則

$$z_{i+j}+x_jy_i+c\ \le\ (\beta-1)+(\beta-1)^2+(\beta-1)\ =\ \beta^2-1 .$$

也就是兩個單字組的加數，加上一個雙字組的乘積，仍然小於 $\beta^2$。因此高字組 $u<\beta$，下一步的進位 $c$ 仍是一個字組，論證可以一路重複。

以 $w=8$ 為例，$255+255^2+255=65535=2^{16}-1$，恰好是 16 位元能表示的最大數。處理器的「乘法得雙字組結果」與「帶進位的加法」指令，就是為這一步設計的。

手算小例：$\beta=10$，$87\times96$

$x=(x_1x_0)_{10}=(87)_{10}$，$y=(y_1y_0)_{10}=(96)_{10}$，$s=2$。

  • $i=0$（乘 $y_0=6$）：$0+7\cdot6+0=42$，寫 2、進位 4；$0+8\cdot6+4=52$，寫 2、進位 5，$z_2\leftarrow5$。此時 $(z_3z_2z_1z_0)_{10}=0522$。
  • $i=1$（乘 $y_1=9$）：$2+7\cdot9+0=65$，寫 5、進位 6；$5+8\cdot9+6=83$，寫 3、進位 8，$z_3\leftarrow8$。結果 $8352$。

每一步的值最多是 $9+9^2+9=99=10^2-1$，兩位數放得下。驗算：$87\cdot96=8352$。共 $s^2=4$ 次字組乘法。

P-256 在 64 位元機器上是 $4^2=16$ 次字組乘法；P-521 是 $9^2=81$ 次。

下面的程式中，s 即本文的 $s$（字組數），w 是字組大小。

Python 參考實作（選讀）：字組表示與 schoolbook 乘法（HAC 演算法 14.12）
def to_words(x, w, s):
    """把 x 拆成 s 個 w 位元字組，由低到高：x = sum(words[i] * 2^(w*i))。"""
    mask = (1 << w) - 1
    return [(x >> (w * i)) & mask for i in range(s)]


def from_words(words, w):
    return sum(d << (w * i) for i, d in enumerate(words))


def schoolbook(xw, yw, w):
    """HAC Alg. 14.12：逐字組相乘，每次只處理一個 2w 位元的乘積與進位。"""
    n, t = len(xw), len(yw)
    mask = (1 << w) - 1
    out = [0] * (n + t)
    for i in range(t):
        carry = 0
        for j in range(n):
            uv = out[i + j] + xw[j] * yw[i] + carry   # 一定小於 2^(2w)
            out[i + j] = uv & mask
            carry = uv >> w
        out[i + n] = carry
    return out

6.4平方：對稱讓字組乘法減半

第 4、5 章的點運算公式把 $\mathbf S$ 和 $\mathbf M$ 分開計算，並假設 $\mathbf S\approx0.8\,\mathbf M$（定義 1.13）。理由在這一節：當 $x=y$ 時，交叉項成對出現，$x_ix_j=x_jx_i$，所以

$$x^2=\sum_{i}x_i^2\,\beta^{\,2i}+2\sum_{i<j}x_ix_j\,\beta^{\,i+j}.$$

不同的乘積只有 $s$ 個平方加上 $s(s-1)/2$ 個交叉項。

演算法 6.5多精度平方HAC Alg. 14.16
輸入$x=(x_{s-1}\cdots x_0)_\beta$。
輸出$x^2=(z_{2s-1}\cdots z_0)_\beta$。
  1. 對 $i=0,1,\dots,2s-1$：$z_i\leftarrow0$。
  2. 對 $i=0,1,\dots,s-1$：
    1. $(uv)_\beta\leftarrow z_{2i}+x_i\cdot x_i$，令 $z_{2i}\leftarrow v$，$c\leftarrow u$。
    2. 對 $j=i+1,\dots,s-1$：$(uv)_\beta\leftarrow z_{i+j}+2x_jx_i+c$，令 $z_{i+j}\leftarrow v$，$c\leftarrow u$。
    3. $z_{i+s}\leftarrow u$。
  3. 回傳 $(z_{2s-1}\cdots z_0)_\beta$。

字組乘法共 $s+s(s-1)/2=s(s+1)/2$ 次（乘 2 只是左移一位，不計），約為 schoolbook 的一半。注意第 2(b) 步的值可達 $(\beta-1)(2\beta+1)$，所以這裡的高位 $u$ 最大到 $2(\beta-1)$，比一個字組多一個位元，實作必須多留這個位元（HAC Note 14.17）。

$s$乘法 $s^2$平方 $s(s+1)/2$
4（P-256，$w=64$）1610
8（P-256，$w=32$）6436
9（P-521，$w=64$）8145

字組乘法少了將近一半，但加法、進位與化簡（第 7–9 章）並沒有減半，所以整個 $\mathbb F_p$ 平方的節省少於一半。$\mathbf S\approx0.8\,\mathbf M$ 是估算用的經驗值，實際比例依實作而定（HMV §2.2.3）。

6.5Karatsuba：用加減法換掉一次乘法

Schoolbook 的 $s^2$ 能不能再少？當 $s$ 很大（例如 RSA 的數有幾十個字組）時，字組乘法的次數主導一切，值得用更多的加減法去換更少的乘法。Karatsuba 的方法就是這樣的交換。

定理 6.6Karatsuba 恆等式HMV §2.2.2；HAC §14.8

設 $s$ 是偶數，$B=\beta^{s/2}$，把 $x,y$ 各切成高低兩半：$x=x_1B+x_0$，$y=y_1B+y_0$，其中 $0\le x_0,x_1,y_0,y_1<B$。則

$$x\,y=x_1y_1\,B^2+\bigl[(x_1+x_0)(y_1+y_0)-x_1y_1-x_0y_0\bigr]B+x_0y_0 .$$

所以一個 $s$ 字組的乘法只需要三個半長的乘積 $x_1y_1$、$x_0y_0$、$(x_1+x_0)(y_1+y_0)$，再加上幾次加減法，而不是直接展開的四個。

把同一個恆等式遞迴用在三個半長乘積上，直到剩一個字組。在理想化的計數下（假設 $s$ 是 2 的冪，並忽略 $x_1+x_0$、$y_1+y_0$ 可能比 $B$ 多出的一個進位位元），字組乘法的次數是 $3^{\log_2 s}=s^{\log_2 3}\approx s^{1.585}$，而不是 $s^2$：$s=4$ 時 9 對 16，$s=32$ 時 243 對 1024。實作還要處理那個多出來的位元。

在 ECC 的大小（$s$ 只有 4 到 9），多出來的加減法、進位處理與分支，往往把省下的幾次字組乘法吃掉，所以常見的實作直接用 schoolbook，或只做一層 Karatsuba（HMV §2.2.2）。上千位元的 RSA 才明顯受益。

Python 參考實作（選讀）：Karatsuba 乘法（遞迴到 32 位元以下改用直接相乘）
def karatsuba(x, y, n):
    """x, y 都小於 2^n。三次半長乘法取代四次。"""
    if n <= 32:
        return x * y
    h = n // 2
    x1, x0 = x >> h, x & ((1 << h) - 1)
    y1, y0 = y >> h, y & ((1 << h) - 1)
    z2 = karatsuba(x1, y1, n - h)
    z0 = karatsuba(x0, y0, h)
    z1 = karatsuba(x1 + x0, y1 + y0, n - h + 1) - z2 - z0
    return (z2 << (2 * h)) + (z1 << h) + z0

6.6互動：schoolbook 乘法逐格演示

選字組大小 $w$ 與字組數 $s$，按「隨機 x, y」產生兩個 $s$ 字組的數。格子的第 $i$ 列、第 $j$ 行是部分積 $x_j\cdot y_i$，它加到輸出的第 $i+j$ 個字組 $z_{i+j}$。播放時目前的格子以橙色標出，下方的輸出列同步更新；每一列結束時，最後的進位寫入第 $i+s$ 個字組。「全部取最大值」讓 $x=y=\beta^s-1$，可以看到內積運算逼近 定理 6.4 的上界 $\beta^2-1$。

6.7乘完之後：$2s$ 個字組要變回 $s$ 個

不管用 schoolbook、平方或 Karatsuba，兩個 $\mathbb F_p$ 元素的整數乘積都有至多 $2s$ 個字組，落在 $[0,p^2)$。要讓它回到 $\mathbb F_p$ 的代表元 $[0,p)$，還得算 $ab\bmod p$（定義 1.1）。照字面做就是一次多字組的長除法：每一步都要估出商的一個字組，比本章的乘法還慢。接下來三章處理這個化簡：第 7 章利用 $p$ 本身的特殊形狀，第 8、9 章處理沒有特殊形狀的模數。
