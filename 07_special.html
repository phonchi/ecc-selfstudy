第 7 章 · Special Moduli

特殊形式的模數

選一個「長得好看」的 p，讓 mod p 只剩加減與移位

成本鏈協定 ECDH→純量乘法 kP→加點／倍點→模乘 mod p→字組乘法

7.1不做除法，能不能化簡？

動機

第 6 章結束時，兩個 $\mathbb F_p$ 元素 $x,y\in[0,p)$ 的整數乘積 $A=x\cdot y$ 已經算好：$0\le A<p^2$，有 $2s$ 個字組。剩下的工作是求 $A\bmod p$（定義 1.1）。照字面做是一次多字組的長除法，比乘法本身還慢；而一次純量乘法要做幾千次這樣的化簡。

本章的想法是：模數 $p$ 是設計曲線的人挑的，那就挑一個讓化簡變容易的 $p$。若 $p$ 很接近 2 的冪，「除以 $p$」可以換成移位、加法和小常數乘法。NIST 的 P-256、P-521，以及 Curve25519、Curve448 的模數都是這樣挑出來的。第 8、9 章再處理沒辦法挑的模數。

7.2折疊恆等式與三類特殊模數

整個章節只用到一個觀察。若 $p=2^L-c$（$L$ 是正整數，通常就是 $p$ 的位元數），則 $2^L=p+c$，所以 $2^L\equiv c\pmod p$（定義 1.2）：$2^L$ 這個「大」的量，模 $p$ 等於 $c$。

定理 7.1折疊恆等式HAC §14.3.4

設 $p=2^L-c$，其中 $c$ 是整數。對整數 $A\ge0$，令 $A_1=\lfloor A/2^L\rfloor$、$A_0=A\bmod 2^L$，即 $A=A_1\cdot2^L+A_0$，$0\le A_0<2^L$。則

$$A\equiv A_0+c\,A_1\pmod p .$$

若 $0<c<2^L$ 且 $A_1>0$，右邊嚴格小於 $A$。

把 $A$ 的高位部分 $A_1$「折」回低位、乘上 $c$ 再加起來，這個動作稱為折疊（folding）。同餘類不變，數值變小。因為電腦裡的整數本來就是二進位，求 $A_1,A_0$ 只是取出位元；若 $L$ 是字組大小 $w$ 的倍數（定義 6.1），甚至只是取出某些字組。所以折疊的成本取決於 $c$ 有多「簡單」。依 $c$ 的形狀，常見的特殊模數分成三類。

定義 7.2Mersenne 質數、偽 Mersenne 質數、Crandall 質數HAC §14.3.4；SP 800-186 App. G.1

形如 $2^L-1$ 的質數稱為 Mersenne 質數。形如 $p=2^L-c$、其中 $c$ 是小的正整數（例如 $c$ 只佔一個字組）的質數，稱為偽 Mersenne 質數（pseudo-Mersenne prime），也叫 Crandall 質數。

定義 7.3廣義 Mersenne 數、Solinas 質數Solinas 1999；SP 800-186 App. G.1；HMV §2.2.6

設 $f(X)=X^d+f_{d-1}X^{d-1}+\cdots+f_0$ 是次數 $d$ 很小、係數 $f_i$ 都是很小的整數（典型是 $0,\pm1$）的多項式，$v$ 是正整數。形如 $p=f(2^v)$ 的質數稱為廣義 Mersenne 數（generalized Mersenne number），或 Solinas 質數。當 $v$ 是字組大小的倍數時，每一項 $2^{vi}$ 都落在字組邊界上。

本章的四個例子：

模數類別$2^L\equiv c$ 中的 $c$用在
$2^{521}-1$Mersenne$1$P-521
$2^{255}-19$偽 Mersenne$19$Curve25519
$2^{448}-2^{224}-1$Solinas$2^{224}+1$Curve448
$2^{256}-2^{224}+2^{192}+2^{96}-1$Solinas$2^{224}-2^{192}-2^{96}+1$P-256

後兩個是 Solinas 質數：Goldilocks 是 $f(X)=X^2-X-1$、$v=224$；P-256 是 $f(X)=X^8-X^7+X^6+X^3-1$、$v=32$。它們的 $c$ 不小，但它是少數幾個 2 的冪的和或差，而且次方都落在字組邊界上，所以「乘 $c$」仍然只是移位與加減。SP 800-186 附錄 G.1 把 P-224 到 P-521 的模數稱為 generalized Mersenne numbers，把 Curve25519、Curve448 的模數稱為 Crandall primes；Curve448 的模數同時也符合上面 Solinas 的形式。

定義 7.4塊的並排SP 800-186 App. G.1

給定塊寬 $t$，若 $0\le X_i<2^t$，記

$$(X_{q-1}\Vert\cdots\Vert X_1\Vert X_0)=\sum_{i=0}^{q-1}X_i\,2^{ti},$$

也就是把 $q$ 個 $t$ 位元的塊由高到低並排成一個 $qt$ 位元的數。本章每次使用時都會寫明 $t$。

7.3Mersenne：P-521 的 $2^{521}-1$

最乾淨的情形是 $c=1$。這時 定理 7.1 變成 $A\equiv A_0+A_1$：化簡只要一次加法。NIST 的 P-521 就用 Mersenne 質數 $p=2^{521}-1$。

演算法 7.5化簡模 2^521 − 1HMV Alg. 2.31；SP 800-186 App. G.1.4
輸入$p=2^{521}-1$，整數 $0\le A<p^2$，寫成 $A=(A_1\Vert A_0)$（每塊 521 位元）。
輸出$A\bmod p$。
  1. $r\leftarrow A_0+A_1$。
  2. 若 $r\ge p$，則 $r\leftarrow r-p$。
  3. 回傳 $r$。

$r\equiv A$ 來自 $2^{521}\equiv1$。因為 $A_0\le p$、$A_1<p$（由 $A<p^2$），所以 $r<2p$，最多減一次。成本是一次 521 位元的加法。

521 不是 64 的倍數（$521=8\cdot64+9$），所以在 64 位元機器上，$A_1$ 要從第 9 個字組的中間開始取，需要一次跨字組的移位，這是唯一的麻煩。

手算小例：$p=2^7-1=127$

取 $x=100$、$y=113$，$A=11300$。以 7 位元為塊寬，$A=(\underbrace{1011000}_{A_1=88}\Vert\underbrace{0100100}_{A_0=36})$。所以

$$A\equiv 88+36=124\pmod{127},$$

而 $124<127$，不必再減。驗算：$11300=88\cdot127+124$。

7.4偽 Mersenne：$2^{255}-19$

Mersenne 質數很少（$L$ 本身必須是質數，而且大多數這樣的 $2^L-1$ 仍是合數），密碼學需要的大小不一定剛好有。放寬成 $c$ 小的偽 Mersenne 質數，選擇就多了。最著名的例子是 $p=2^{255}-19$，Curve25519 的底體（RFC 7748）。這時 $2^{255}\equiv19$，每次折疊多一次「乘 19」。

演算法 7.6化簡模 2^255 − 19（兩次折疊）HAC Alg. 14.47（$b=2,\ t=255,\ c=19$）
輸入$p=2^{255}-19$，整數 $0\le A<p^2$。
輸出$A\bmod p$。
  1. 寫 $A=(A_1\Vert A_0)$（每塊 255 位元）；$r\leftarrow A_0+19A_1$。
  2. 再寫 $r=(r_1\Vert r_0)$（每塊 255 位元）；$r\leftarrow r_0+19r_1$。
  3. 若 $r\ge p$，則 $r\leftarrow r-p$。
  4. 回傳 $r$。

兩步都是 定理 7.1，所以 $r\equiv A$。第 1 步後 $r<2^{255}+19\cdot2^{255}=20\cdot2^{255}<2^{260}$，比 $p$ 大，所以要再折一次；這時 $r_1<20$，第 2 步後 $r<2^{255}+19\cdot19<2p$，最多再減一次。

注意 7.7只借用模數

Curve25519 這條曲線是 Montgomery 形式 $v^2=u^3+486662u^2+u$（RFC 7748），不是本站其他章用的短 Weierstrass 形式。這裡只借用它的模數來說明折疊，與曲線的形式無關。

7.5Solinas：Goldilocks $2^{448}-2^{224}-1$

再放寬一步：$c$ 不必小，只要它是少數幾個落在塊邊界上的 2 的冪。Curve448 用的 $p=2^{448}-2^{224}-1$ 就是一例（因為形狀漂亮，常被叫做 Goldilocks）。以 224 位元為塊寬，$2^{448}\equiv2^{224}+1$，而且

$$2^{672}=2^{224}\cdot2^{448}\equiv2^{448}+2^{224}\equiv2^{225}+1\pmod p .$$

把 $A=(A_3\Vert A_2\Vert A_1\Vert A_0)$（每塊 224 位元）的高次方逐一換掉：$A_2\cdot2^{448}\equiv(A_2\Vert A_2)$，$A_3\cdot2^{672}\equiv A_3\cdot2^{225}+A_3$，也就是 $(A_3\Vert A_3)+(A_3\Vert0)$。

演算法 7.8化簡模 2^448 − 2^224 − 1SP 800-186 App. G.1.6
輸入$p=2^{448}-2^{224}-1$，整數 $0\le A<p^2$，寫成 $A=(A_3\Vert A_2\Vert A_1\Vert A_0)$（每塊 224 位元）。
輸出$A\bmod p$。
  1. 定義四個 448 位元的數（每塊 224 位元）：$S_1=(A_1\Vert A_0)$，$S_2=(A_2\Vert A_2)$，$S_3=(A_3\Vert A_3)$，$S_4=(A_3\Vert 0)$。
  2. $r\leftarrow S_1+S_2+S_3+S_4$。
  3. 當 $r\ge p$：$r\leftarrow r-p$。
  4. 回傳 $r$。

上面的兩個同餘式給出 $S_1+S_2+S_3+S_4\equiv A$。四項各小於 $2^{448}$，所以 $r<4\cdot2^{448}$，而 $4\cdot2^{448}-4p=4(2^{224}+1)<p$，第 3 步至多減四次。

注意：單獨一項 $S_i$ 與 $A$ 沒有同餘關係；只有四項全部加完，總和才與 $A$ 同餘。

7.6P-256：九項的加減

P-256 的模數 $p=2^{256}-2^{224}+2^{192}+2^{96}-1$ 看起來比上面幾個複雜，為什麼要選這個形狀？關鍵是每個次方 $256,224,192,96,0$ 都是 32 的倍數。由 定理 7.1，

$$2^{256}\equiv2^{224}-2^{192}-2^{96}+1\pmod p ,$$

右邊每一項都是 $2^{32i}$ 的形式。所以若以 32 位元字組寫 $A=(A_{15}\Vert\cdots\Vert A_1\Vert A_0)$（每塊 32 位元），把 $2^{256},2^{288},\dots,2^{480}$ 一個個換成 $2^0,2^{32},\dots,2^{224}$ 的組合，每個 $A_j$ 都整塊落到某些字組位置上，不必在字組內部移位，而且係數只有 $0,\pm1,\pm2$。這正是設計者要的：在 32 位元機器上，化簡只剩字組的重排與加減。

演算法 7.9化簡模 P-256 的 pHMV Alg. 2.29；SP 800-186 App. G.1.2
輸入$p=2^{256}-2^{224}+2^{192}+2^{96}-1$，整數 $0\le A<p^2$，寫成 $A=(A_{15}\Vert A_{14}\Vert\cdots\Vert A_0)$（每塊 32 位元）。
輸出$A\bmod p$。
  1. 定義九個 256 位元的數 $T,S_1,\dots,S_4,D_1,\dots,D_4$，每個由 8 塊 32 位元字組並排而成，例如 $T=(A_7\Vert A_6\Vert\cdots\Vert A_0)$、$S_1=(A_{15}\Vert A_{14}\Vert A_{13}\Vert A_{12}\Vert A_{11}\Vert0\Vert0\Vert0)$；全部九項見下表（由左到右是字組 7 到字組 0）。
  2. $U\leftarrow T+2S_1+2S_2+S_3+S_4$；再令 $U\leftarrow U-D_1-D_2-D_3-D_4$。
  3. 當 $U<0$：$U\leftarrow U+p$。當 $U\ge p$：$U\leftarrow U-p$。
  4. 回傳 $U$。

$U\equiv A\pmod p$ 是把每個 $2^{32j}$（$8\le j\le15$）用 $2^{256}$ 的同餘式反覆換掉後整理的結果。每一項都在 $[0,2^{256})$，所以 $-4\cdot2^{256}<U<7\cdot2^{256}$，第 3 步至多加 5 次或減 7 次 $p$。HMV 把同樣九項記作 $s_1,\dots,s_9$。

和 Goldilocks 一樣，九項必須全部加減完，總和 $U$ 才與 $A$ 同餘；中間的部分和沒有這個性質。而且 $U$ 可能是負數，也可能比 $p$ 大好幾倍，所以第 3 步的正規化（加或減若干次 $p$，把結果拉回 $[0,p)$）不可省略。這一步的次數隨資料而變；常數時間的實作會改成固定次數的條件加減，用遮罩選結果。

下面的程式中，四個函式依序對應 演算法 7.5、演算法 7.6、演算法 7.8、演算法 7.9（$2^{255}-19$ 的版本以迴圈折到不能再折為止，效果與兩次折疊相同）。

Python 參考實作（選讀）：四種折疊（SP 800-186 附錄 G.1）
def fold_p521(A):
    """p = 2^521 - 1，A < p^2。2^521 = 1 (mod p)，所以高半部直接加回低半部。"""
    p = (1 << 521) - 1
    B = (A & p) + (A >> 521)
    return B - p if B >= p else B


def fold_25519(A):
    """p = 2^255 - 19。2^255 = 19 (mod p)，所以高半部乘 19 加回來。"""
    p = (1 << 255) - 19
    while A >> 255:
        A = (A & ((1 << 255) - 1)) + 19 * (A >> 255)
    return A - p if A >= p else A


def fold_448(A):
    """p = 2^448 - 2^224 - 1（Goldilocks）。SP 800-186 G.1.6，224 位元字組。"""
    p = (1 << 448) - (1 << 224) - 1
    A0, A1, A2, A3 = to_words(A, 224, 4)
    cat = lambda hi, lo: (hi << 224) | lo
    B = cat(A1, A0) + cat(A2, A2) + cat(A3, A3) + cat(A3, 0)
    while B >= p:
        B -= p
    return B


def fold_p256(A):
    """p = 2^256 - 2^224 + 2^192 + 2^96 - 1。SP 800-186 G.1.2，32 位元字組。"""
    p = (1 << 256) - (1 << 224) + (1 << 192) + (1 << 96) - 1
    a = to_words(A, 32, 16)
    def cat(*ws):                       # 由高到低列出 8 個字組
        return from_words(list(reversed(ws)), 32)
    T  = cat(a[7], a[6], a[5], a[4], a[3], a[2], a[1], a[0])
    S1 = cat(a[15], a[14], a[13], a[12], a[11], 0, 0, 0)
    S2 = cat(0, a[15], a[14], a[13], a[12], 0, 0, 0)
    S3 = cat(a[15], a[14], 0, 0, 0, a[10], a[9], a[8])
    S4 = cat(a[8], a[13], a[15], a[14], a[13], a[11], a[10], a[9])
    D1 = cat(a[10], a[8], 0, 0, 0, a[13], a[12], a[11])
    D2 = cat(a[11], a[9], 0, 0, a[15], a[14], a[13], a[12])
    D3 = cat(a[12], 0, a[10], a[9], a[8], a[15], a[14], a[13])
    D4 = cat(a[13], 0, a[11], a[10], a[9], 0, a[15], a[14])
    B = T + 2 * S1 + 2 * S2 + S3 + S4 - D1 - D2 - D3 - D4
    while B < 0:                        # 結果落在 (-4·2^256, 7·2^256)，加減幾次 p 即可
        B += p
    while B >= p:
        B -= p
    return B

7.7互動：折疊實驗室

選一個模數，按「隨機乘積」產生 $A=x\cdot y$（$x,y$ 是隨機的體元素），再逐步播放。藍色是要折回去的高位部分，綠色是低位部分。Mersenne 與偽 Mersenne 的每一次折疊都讓值變小，而模 $p$ 的同餘類不變。Goldilocks 與 P-256 則要把所有項加完，總和才與 $A$ 同餘；中間的部分和不一定同餘，P-256 的總和甚至可能是負數，最後再加減 $p$ 正規化。最後一行與直接算 A % p 比對。

7.8特殊模數的代價

折疊這麼快，為什麼還需要第 8、9 章的一般方法？

  • 模數不一定能挑。曲線的底體 $p$ 可以挑，但 ECDSA 簽章還要在模基點的階 $n$下計算（第 8 章開頭說明），而 $n$ 由曲線決定，通常沒有特殊形狀；RSA 的模數更是兩個隨機質數的乘積。
  • 每個模數要一套專用程式。折疊規則是為某一個 $p$ 量身打造的；一般方法只要換掉預先算好的常數，就能用在任何模數上。
  • 平台不同，最佳選擇不同。P-256 的規則是為 32 位元字組設計的；P-521 的 521 位元不在 64 位元字組邊界上。在某些硬體上，第 9 章的 Montgomery 乘法即使用在特殊模數上也不輸給折疊。

所以本章與後兩章不是互相取代，而是各有用處。第 10 章有一張總比較表。
